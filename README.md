# secondapp

A simple Spring Boot application built with Java 21 and Maven.

## Sample REST endpoints

Run the application, then open these URLs:

- `GET /api/hello` — returns: `Hello! Welcome to Second App.`
- `GET /api/welcome` — returns: `Welcome! Your secondapp endpoints are working.`

For a local application running on the default Spring Boot port:

- http://localhost:8080/api/hello
- http://localhost:8080/api/welcome
